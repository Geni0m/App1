# Illustrations Roulette JDR : prompts pour ChatGPT

350 images en tout : 27 races, 16 bâtiments, 67 métiers, 240 événements.

Conseil : commencez par les races et les métiers, ce sont les images les plus vues.

## 1. Message de départ (à coller une seule fois)

```
Tu vas me créer une série d’illustrations pour mon jeu de rôle « Roulette JDR » (univers médiéval-fantastique, ton chaleureux et un peu épique).

Style à respecter pour TOUTES les images :
- peinture numérique façon illustration de livre de contes, coups de pinceau visibles
- lumière douce et dorée, palette chaude (ocres, verts profonds, bleus nuit)
- format paysage 3:2 (1536×1024), sujet bien centré (l’image sera recadrée en bandeau)
- aucun texte, aucune lettre, aucun logo, aucun cadre
- fond simple et lisible, pas de détails minuscules

Je vais t’envoyer des listes. Pour chaque ligne, génère UNE image, l’une après l’autre, puis attends que je dise « suite ». Garde exactement le même style d’une image à l’autre.
```

## 2. Les listes à envoyer (par paquets de 5)

Copiez un bloc, envoyez-le, puis écrivez « suite » pour chaque image suivante. Le nom à gauche est le **nom du fichier** à donner à l’image.

## 3. Mettre les images dans l’application

**Option A : directement sur l’iPhone (sans renommer)**
Onglet Réglages (barre du bas) → section « Images (même cachées) » → choisissez la catégorie, cherchez le nom → « Ajouter une image » → choisissez l’image enregistrée depuis ChatGPT.
Les images restent sur ce téléphone (et sont incluses dans la sauvegarde complète).

**Option B : sur GitHub (visibles sur tous les appareils)**
Renommez chaque image avec le nom de fichier indiqué (ex. `race-elfe.png`), puis sur GitHub : dossier `img/` → « Add file » → « Upload files ».
Les formats .png, .jpg et .webp marchent. Réduisez-les si possible (environ 800 px de large) pour que l’app reste rapide.
