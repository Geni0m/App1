      Modifier les tables

      Une option par ligne : texte | poids | Réponse=multiplicateur; …
      Le multiplicateur s'applique si le personnage a déjà cette réponse, ou si l'un de ses deux derniers événements porte ce nom (0 = exclu, 3 = trois fois plus probable). Un événement commençant par « Voyage » ouvre la carte ; les options de « Décor » sont les lieux.
